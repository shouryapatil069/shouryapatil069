## Featured Projects

<details>
<summary><strong>Codebase Explainer — Plain-English Source Code Analysis</strong></summary>

<br/>

A developer-focused application that converts source code into structured, beginner-friendly explanations. It identifies important code elements and organizes its output into clear sections such as purpose, execution flow, data flow and function breakdown.

| Category        | Details                                                                            |
| :-------------- | :--------------------------------------------------------------------------------- |
| **Stack**       | React, TypeScript, Vite and custom code-analysis modules                           |
| **Scale**       | Multi-language explanation modes for JavaScript, React, Python, HTML and CSS       |
| **Performance** | Lightweight client-side analysis with isolated language detection                  |
| **Security**    | Local analysis mode avoids sending source code to external services                |
| **Impact**      | Helps students and beginner developers understand unfamiliar codebases             |
| **Repository**  | [Explore GitHub repositories](https://github.com/shouryapatil069?tab=repositories) |

The project uses separate analysis logic for different programming languages. Its React engine detects components, props, state hooks, effects, event handlers, conditional rendering, list rendering and returned JSX.

The output follows a consistent explanation format:

1. Simple Summary
2. Main Purpose
3. Important Parts
4. Step-by-Step Flow
5. Data Flow
6. Function Breakdown
7. Framework-Specific Breakdown
8. Beginner Explanation

</details>

<details>
<summary><strong>AirLink — Gesture-Controlled Drawing Experience</strong></summary>

<br/>

AirLink is an interactive drawing application that allows users to control a digital canvas through hand gestures captured by their camera.

| Category        | Details                                                                            |
| :-------------- | :--------------------------------------------------------------------------------- |
| **Stack**       | React, Vite, MediaPipe Hands, Fabric.js, Zustand and Framer Motion                 |
| **Scale**       | Real-time gesture detection with drawing, erasing and canvas controls              |
| **Performance** | Client-side camera processing designed for responsive interaction                  |
| **Security**    | Camera access is permission-based and processing occurs in the browser             |
| **Impact**      | Demonstrates accessible, touch-free interaction through computer vision            |
| **Repository**  | [Explore GitHub repositories](https://github.com/shouryapatil069?tab=repositories) |

The application focuses on accurate index-finger tracking instead of treating the entire hand as a drawing input. It includes gesture-based drawing, erasing, colour selection, canvas clearing and camera lifecycle management.

Its interface uses a minimal dark visual system with subtle neon accents, clear permissions and responsive interaction feedback.

</details>

<br/>

<details>
<summary><strong>RepLog — Workout Progress Tracker</strong></summary>

<br/>

RepLog is a full-stack workout tracking platform designed to help users record exercises, monitor sessions and maintain a structured history of their training.

| Category        | Details                                                                            |
| :-------------- | :--------------------------------------------------------------------------------- |
| **Stack**       | React, Vite, Node.js, Express, MongoDB and Mongoose                                |
| **Scale**       | Full CRUD workflow for workout records                                             |
| **Performance** | Modular API layer with separate frontend and backend responsibilities              |
| **Security**    | Environment variables protect database configuration and sensitive values          |
| **Impact**      | Makes workout logging and progress review more organized                           |
| **Repository**  | [Explore GitHub repositories](https://github.com/shouryapatil069?tab=repositories) |

The backend uses a clean controller, route, model and configuration structure. It supports creating, reading, updating and deleting workout logs through RESTful API endpoints.

The frontend supports both local and backend-powered workflows through a configurable API environment, allowing the application to remain flexible during development and deployment.

</details>

<details>
<summary><strong>README Auto-Generator — Structured Documentation Builder</strong></summary>

<br/>

A developer productivity tool that generates organized Markdown documentation based on project information entered through a simple interface.

| Category        | Details                                                                           |
| :-------------- | :-------------------------------------------------------------------------------- |
| **Stack**       | React, JavaScript, Vite and Markdown generation logic                             |
| **Scale**       | Multiple templates for different project and audience requirements                |
| **Performance** | Instant client-side Markdown generation                                           |
| **Security**    | No account or sensitive data collection required                                  |
| **Impact**      | Reduces the time required to create professional project documentation            |
| **Repository**  | [readme-auto-generator](https://github.com/shouryapatil069/readme-auto-generator) |

The application includes four documentation styles:

* Minimal
* Professional
* Open Source
* Beginner Friendly

Each template dynamically displays relevant fields such as features, technology stack, folder structure, usage examples, future enhancements and author details.

Generated Markdown can be copied directly or downloaded as a README file.
